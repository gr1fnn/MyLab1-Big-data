# Murder Mystery Analyzer

## Описание

**Murder Mystery Analyzer** - это профессиональное приложение для анализа детективной базы данных "Murder Mystery". Программа предоставляет комплексный инструментарий для подключения к PostgreSQL базе данных, объединения таблиц, визуализации данных и проведения статистического анализа.

## Основные возможности

### 🔌 Подключение к базе данных
- Автоматическое обнаружение всех таблиц в базе данных
- Настраиваемые параметры подключения (хост, порт, пользователь, пароль)
- Тестирование подключения перед загрузкой данных
- Индикация прогресса загрузки

### 📊 Управление данными
- Загрузка всех таблиц из базы данных
- 4 режима объединения данных:
  - Основные демографические признаки
  - Полный набор признаков  
  - Демография + Доходы + Автомобили
  - Все доступные данные
- Предпросмотр структуры объединенной таблицы

### 📈 Анализ и визуализация
#### Одномерный анализ:
- Построение 2 гистограмм распределения
- Выбор признаков для анализа (Возраст, Доход, Рост, Вес)
- Настройка количества бинов (10-100)
- Автоматический расчет статистики

#### Многомерный анализ:
- 4 типа графиков на выбор:
  - Доход-Возраст-Пол (диаграмма рассеяния)
  - Автомобили-Доход-Пол (группированные столбцы)
  - Преступления по городам (столбчатая диаграмма)
  - Корреляционная матрица (тепловая карта)
- Детальные текстовые отчеты с выводами

## Технологический стек

- **Python 3.8+**
- **PySide6** - для графического интерфейса
- **PostgreSQL** - база данных
- **pandas** - обработка и анализ данных
- **matplotlib** - построение графиков и диаграмм
- **seaborn** - улучшенная визуализация
- **psycopg2** - подключение к PostgreSQL
- **numpy** - численные вычисления

## Инструкции по запуску

### Предварительные требования

1. **Установите Python 3.8 или выше**
2. **Установите PostgreSQL** и создайте базу данных "Murder Mystery"
3. **Импортируйте данные** в базу из предоставленных SQL-файлов
