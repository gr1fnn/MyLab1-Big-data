## 🎯 О проекте

Данный веб-сервис представляет собой витрину данных для анализа базы данных **Murder Mystery** — детективной базы данных, содержащей информацию о преступлениях, подозреваемых, их доходах, водительских правах и других характеристиках. Приложение позволяет визуализировать результаты SQL-запросов из практической работы №1 в интерактивном формате.

### Цели разработки:

1. Создать удобный интерфейс для просмотра результатов исследования данных
2. Визуализировать результаты SQL-запросов в виде интерактивных графиков
3. Реализовать многостраничную структуру согласно требованиям
4. Обеспечить возможность расширения для работы с машинным обучением

## ✨ Функциональность

### Основные разделы:

#### 1. **Общее описание проекта**
- 📋 Информация о проекте и его целях
- 📊 Структура базы данных (7 таблиц)
- 📈 Статистика подключения к БД
- 🔍 Описание источников данных

#### 2. **Основные результаты EDA** (6 вкладок)

| Вкладка | Описание | Визуализация |
|---------|----------|--------------|
| **Анализ доходов по улицам** | Распределение средних доходов по улицам | Столбчатые диаграммы, метрики |
| **Анализ автомобилей** | Связь между маркой авто, полом и доходом | Пузырьковые диаграммы, фильтры |
| **Возрастные группы** | Доходы в разрезе возрастных категорий | Групповые столбцы, тепловые карты |
| **Детальный анализ автомобилей** | Сравнение доходов владельцев | Сравнительные графики |
| **Анализ членов спортзала** | Демография посетителей | Круговые диаграммы, метрики |
| **Общая статистика** | Информация о БД и тестовые данные | Сводные таблицы |

#### 3. **Обучающая и тестовая выборка**
- 🔄 Подготовка данных для ML (4 этапа)
- 📚 Обучающая выборка (80% данных)
- 🧪 Тестовая выборка (20% данных)
- 📊 Метрики качества и важность признаков

### Интерактивные возможности:

- ✅ Подключение к базе данных через боковую панель
- ✅ Фильтрация данных по различным параметрам
- ✅ Интерактивные графики с возможностью масштабирования
- ✅ Отображение времени выполнения запросов
- ✅ Адаптивный дизайн для всех устройств

## 🛠 Технологический стек

- **Python 3.9+** - основной язык программирования
- **Streamlit 1.28.1** - фреймворк для веб-приложений
- **Pandas 2.0.3** - обработка и анализ данных
- **Plotly 5.17.0** - интерактивная визуализация
- **psycopg2-binary 2.9.7** - подключение к PostgreSQL
- **PostgreSQL** - база данных Murder Mystery

## 🚀 Установка и запуск

### Предварительные требования

- Python 3.9 или выше
- pip (менеджер пакетов Python)
- Доступ к базе данных Murder Mystery
